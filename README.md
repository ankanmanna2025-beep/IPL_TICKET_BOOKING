# 🏏 IPL 2026 Ticket Booking Website

## 📌 Project Overview
The IPL Ticket Booking Website is a frontend web development project created as part of Activity 1. It provides a simple interface where users can explore IPL teams, view match schedules, and access a ticket booking form.

## 🎯 Objective
To develop the basic structure and design of a responsive IPL Ticket Booking website using HTML5 and CSS3.

## 🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- Visual Studio Code – Code editor
- Live Server – Local development server

## ✨ Features
- Navigation bar with Matches, Book Ticket, My Bookings, and Guidelines
- Hero banner with the tagline "Experience The Stadium Energy Live!"
- IPL teams and major match venues
- Match schedule table with ticket prices
- Team filter dropdown
- Ticket booking form
- Booking summary section
- My Ticket Bookings table
- Guidelines cards
- Footer with copyright information
- CSS styling for layout, colors, buttons, tables, and forms
- Responsive layout for different screen sizes

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/ipl-ticket-booking.git
   ```

2. Open the project folder in Visual Studio Code.
3. Ensure `style.css` is linked inside the HTML `<head>`:

   ```html
   <link rel="stylesheet" href="style.css">
   ```

4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. The website will open in your browser.
